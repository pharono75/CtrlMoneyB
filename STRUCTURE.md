# Структура проекта CtrlMoney

## Обновленная структура после интеграции регистрации

### 📁 Главные папки:

```
src/
├── pages/
│   ├── Landing.jsx              # Лейдинг страница
│   ├── App.css                  # Стили лейдинга
│   ├── registration/             # Папка регистрации
│   │   ├── Register.jsx         # Главный компонент регистрации (5 этапов)
│   │   └── utils/
│   │       └── svgPaths.js      # SVG пути для фонов
│   ├── app/                     # UI компоненты (старые файлы)
│   ├── imports/                 # Старые файлы регистрации TSX (можно удалить)
│   ├── assets/                  # Изображения
│   └── styles/                  # CSS файлы
├── App.jsx                      # Главное приложение с роутингом
├── App.css
├── main.jsx
└── index.css
```

## 🔄 Маршруты приложения:

- `/` - Лейдинг страница (Landing.jsx)
- `/register` - Страница регистрации (Register.jsx)

## 📝 Что было изменено:

### 1. **Register.jsx** 
   - Переконвертирован из TypeScript в JSX
   - Удалены все типизации (interfaces, type annotations)
   - Сохранена полная функциональность регистрации на 5 этапов:
     - Этап 1: Название компании, рабочая почта
     - Этап 2: Номер телефона, количество сотрудников
     - Этап 3: ИНН, использование 1С
     - Этап 4: ФИО, должность
     - Этап 5: Пароль и подтверждение
   - Включены все фишки: эмодзи регионов, автодополнение почты, валидация

### 2. **App.jsx**
   - Добавлен импорт Register
   - Добавлен маршрут `/register`
   - Удален дублирующийся импорт App.css

### 3. **Landing.jsx**
   - Добавлена навигация через useNavigate()
   - Кнопка "Войти" ведет на `/register`
   - Кнопка "Начать сейчас" ведет на `/register`

### 4. **svgPaths.js**
   - Объединены все SVG пути из старых файлов
   - Экспортируются как объекты для использования в компонентах

## 🧹 Что можно удалить:

## 🚀 Как использовать:

1. На лейдинг странице нажать "Войти" или "Начать сейчас"
2. Открывается страница регистрации с 5 этапами
3. Заполнить информацию на каждом этапе
4. На последнем этапе нажать "Готово!"

## 📦 Зависимости:

- `react-router-dom` - для навигации между страницами
- `motion/react` - для анимаций
- `lucide-react` - для иконок
