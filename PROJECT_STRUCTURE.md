# CtrlMoney - Структура проекта

## 📁 Новая структура

```
src/
├── App.jsx                          # Главное приложение с роутингом
├── App.css                          # Стили приложения
├── main.jsx                         # Точка входа
├── index.css                        # Глобальные стили
│
├── assets/                          # Общие ассеты
│   ├── man.svg                      # SVG иконка (логин)
│   └── bg.svg                       # SVG фон
│
├── components/                      # Общие компоненты (UI библиотека)
│   ├── figma/
│   │   └── ImageWithFallback.tsx   # Компонент изображения
│   └── ui/                          # Shadcn/UI компоненты (48 файлов)
│       ├── accordion.tsx
│       ├── alert.tsx
│       ├── button.tsx
│       ├── card.tsx
│       ├── dialog.tsx
│       ├── form.tsx
│       ├── input.tsx
│       └── (... остальные компоненты)
│
└── pages/                           # Страницы приложения
    ├── Landing.jsx                  # Лейдинг страница (главная)
    └── registration/                # Модуль регистрации
        ├── Register.jsx             # Компонент регистрации (5 этапов)
        ├── assets/                  # Ассеты для регистрации
        │   └── (картинки для регистрации)
        ├── styles/                  # Стили регистрации
        │   ├── fonts.css
        │   ├── index.css
        │   ├── tailwind.css
        │   └── theme.css
        └── utils/                   # Утилиты и данные
            ├── svgPaths.js          # SVG пути для фонов
            └── (другие утилиты)
```

## 🔄 Маршруты приложения

| Путь | Компонент | Описание |
|------|-----------|---------|
| `/` | `Landing` | Главная страница с информацией о сервисе |
| `/register` | `Register` | Многоэтапная регистрация |

## 📦 Зависимости

- **react-router-dom** - навигация между страницами
- **motion/react** - анимации
- **lucide-react** - иконки
- **tailwindcss** - утилиты для стилизации

## 🎯 Структура компонентов

### pages/registration/Register.jsx
Многоэтапный компонент регистрации:
- **Этап 1**: Название компании, рабочая почта
- **Этап 2**: Номер телефона, количество сотрудников
- **Этап 3**: ИНН, использование 1С
- **Этап 4**: ФИО, должность
- **Этап 5**: Пароль и подтверждение

### pages/registration/utils/svgPaths.js
Содержит SVG пути для:
- Фоновых градиентов регистрации
- Различных этапов (используется одна база для всех)

### components/
Глобальные компоненты, доступные на всех страницах:
- UI компоненты из Shadcn/UI (кнопки, инпуты, модалы и т.д.)
- Компоненты из Figma (ImageWithFallback)

## 🚀 Особенности

### Landing Page
- Навигационная панель с логотипом и ссылками
- CTA кнопка "Начать сейчас" → ведет на `/register`
- Кнопка "Войти" → ведет на `/register`

### Registration Page
- ✅ 5 этапов с прогресс-баром
- ✅ Валидация на каждом этапе
- ✅ Автодополнение email доменов (@gmail, @yandex и т.д.)
- ✅ Определение региона по номеру телефона (эмодзи)
- ✅ Определение региона по ИНН (эмодзи)
- ✅ Показ провайдера почты (иконка)
- ✅ Валидация пароля (совпадение)
- ✅ Плавные анимации при переходе между этапами

## 💾 Сохраненные данные

Компонент Register хранит в состоянии:
```javascript
{
  companyName: '',        // Название компании
  email: '',              // Рабочая почта
  phone: '+7 ',           // Номер телефона
  employeeCount: '',      // Количество сотрудников
  inn: '',                // ИНН
  use1C: '',              // Использование 1С (Да/Нет/Планирую)
  fullName: '',           // ФИО
  position: '',           // Должность
  password: '',           // Пароль
  confirmPassword: ''     // Подтверждение пароля
}
```

## 🔧 Как расширять проект

### Добавить новую страницу
1. Создать файл в `src/pages/MyPage.jsx`
2. Добавить маршрут в `src/App.jsx`
```jsx
<Route path="/mypage" element={<MyPage />} />
```

### Добавить новый компонент UI
1. Создать файл в `src/components/`
2. Экспортировать компонент
3. Использовать везде в приложении

### Добавить стили
1. Создать CSS файл в `src/styles/`
2. Импортировать в нужный компонент
3. Использовать классы Tailwind + пользовательские классы

## 🎨 Цветовая схема

- Основной серый: `#767d8f`
- Фон регистрации: Gradient (`#e5e5ea` → `#d8d8dd`)
- Белый с прозрачностью: `rgba(255, 255, 255, 0.5)`

## 📝 Важные замечания

- UI компоненты из `src/components/ui/` это готовые компоненты из Shadcn
- Они уже полностью стилизованы с Tailwind CSS
- SVG пути в `utils/svgPaths.js` можно редактировать через Figma экспорт
- Все стили могут быть кастомизированы через Tailwind классы
